# Requirements Snapshot

## Brand and experience
- Product: SpendWise
- Byline: By Riten Kumar
- Default appearance: Dark Graphite, with Light and System options
- Visual direction: monochrome silver/graphite Liquid Glass-inspired interface
- Responsive: mobile, tablet and desktop
- Language: English

## Selected product capabilities
- Dashboard summaries and charts
- Transactions with income/expense, category, timestamp, payment method, wallet, notes, tags and optional location
- Custom categories and payment methods
- Overall and category budgets with 50/75/90/100 percent alert thresholds
- Multiple savings goals and contributions
- Multiple wallets/accounts
- Recurring payments and subscriptions
- Analytics, monthly/weekly/yearly reports and PDF/CSV export
- Expense calendar
- In-app and configurable notification preferences
- Profile, currency, theme, privacy and account settings
- Multi-currency records with original currency retained and converted dashboard totals planned
- Supabase authentication, RLS and private receipt storage

## Important distinction
This requirements snapshot records the intended final scope. It does not imply that every module is fully implemented in the starter ZIP. See README for implementation status.

## Access roles (prototype)
- Personal User: manages their own financial data.
- Administrator: manages application-level user administration where authorised.
- Finance Manager: intended for a controlled finance-management role if required by the final scope.
- Role assignment must be performed by trusted backend/admin processes, never by a public sign-up dropdown. The current role selector is a prototype preview only.
