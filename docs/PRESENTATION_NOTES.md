# Presentation Notes — SpendWise

## Suggested 8–10 minute flow
1. **Introduction:** SpendWise is a personal expense tracker designed to make everyday money management clearer.
2. **Problem:** People often record spending in scattered notes or apps and struggle to see where money goes.
3. **Objective:** Centralise transactions, budgets, savings goals and spending insights in one responsive web app.
4. **Technology:** HTML, CSS and JavaScript provide the interface; Supabase provides authentication and PostgreSQL storage; Chart.js visualises financial activity.
5. **Dashboard demo:** Explain balance, income, expense, cash-flow chart and category breakdown. Use clearly labelled demo data only.
6. **Transactions:** Demonstrate adding, editing, searching, filtering and exporting a transaction.
7. **Planning tools:** Explain budgets, goals, wallets and recurring payments.
8. **Security:** Explain authenticated sessions, per-user RLS policies and private receipt storage design.
9. **Limitations and future scope:** Finish remaining CRUD modules, exchange-rate integration, notification scheduling, PDF export and security testing.
10. **Conclusion:** SpendWise aims to encourage informed, consistent financial habits through accessible personal finance tools.

## Demo safety
Use fictional sample data. Do not show real bank credentials, personal financial statements, private API keys or real customer information during the presentation.
